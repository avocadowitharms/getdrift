Need help with drift, have a question about the waitlist, or want to report a problem? Send a note and include enough context to reproduce the issue.

Contact

What To Include

  • Your operating system and app version, if available.
  • The project or workflow area where the issue happened.
  • Steps to reproduce the problem.
  • Screenshots or logs when they help explain the issue.
